## Projeto de um sistema de Iphone

Bom, nesse projetinho eu desenvolvi um pequeno sistema operacional de um iphone, é bem basicão, mas ajuda a entender o conceito de Interfaces que é a base principal do projeto. O programa foi feito em Java.

Noções que você precisa ter para realizar esse mini projeto:

* Conceitos de Lógica de programação
* Entendimento de POO
* Conhecimentos básicos da Linguagem Java.
